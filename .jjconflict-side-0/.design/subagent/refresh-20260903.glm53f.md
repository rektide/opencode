# Subagent recovery freshen onto 7ba5f3e5

## What was up

The maintained plugin session-reads line (floating bookmark `subagent-recovery`
at `8d8ac622`, plus one docs commit `068d02a0` accumulated above it per the
work-above-the-bookmark rule) sat on `v2@origin` `43d09b9d75ad` with **181
upstream commits** of drift (oldest `04653282`, 2026-09-01). Task: fast-forward
the floating bookmark over the docs commit, audit the gap for semantic

`7ba5f3e5b220` ("fix(core): restore Ctrl+C in Windows terminals (#47163)"),
preserving originals and dated snapshots.

## Collision audit (before touching anything)

**No semantic collision.** Neither tracked proposal —
[#43556](https://github.com/anomalyco/opencode/pull/43556) (plugin session
history reads) nor [#39939](https://github.com/anomalyco/opencode/pull/39939)
(cursor pagination) — landed in the 181-commit gap, and no commit adds plugin
session-read surface: `packages/plugin/src/effect/session.ts` and
`packages/plugin/src/promise/session.ts` are untouched by the entire gap.

**The plugin host/runtime contract DID change at named-context scale** —
upstream `e76e90b7` (#46639, "refactor(core): decouple plugins from config
loading", 131 files, +1349/−10902) deleted the `PluginRuntime` indirection:
`packages/core/src/plugin/runtime.ts` and
`packages/core/test/plugin-session.types.ts` are gone, and the host no longer
binds `PluginRuntime.Service` — it yields services directly
(`const sessions = yield* Session.Service` etc.) and grew a `requirements`
`LayerNode.group` plus a `Pick<Interface, "list">` make signature. This is the
same collision the 2026-09-02 compose already adjudicated (patches.md, compose
incidents): keep the feature's `PluginRuntime`-backed host contract by
restoring the deleted files byte-for-byte from the feature tip and wiring the
runtime back into the host requirements and the test fixture. The freshen
mandate prescribed the same playbook for this recurrence, so it was applied
(see Conflicts). The feature's underlying read surface survived intact:
`Session.Interface` still has `list`/`messages`/`inbox`/`active`/`resume` at
the new tip, `Job`/`PersistentPty`/`LocationServiceMap`/`Location.Info`
constructor/`makeGlobalNode`/schema `ListAnchor`/`ListInput` all still exist,
so the restored modules compile unchanged.

Post-compose delta (8d4ef0162181..v2@origin, ~90 commits) brought **no further
host-contract change**: `4772b6a3` renamed State drafts to editors and
`efefd904`/`962c26bd` added editor lookups (host.ts import/region churn only),
and the test fixture changed only in `Npm.Service` mock signatures.

## Rebase

Duplicate-then-rebase per the manifest. Fast-forwarded floating
`subagent-recovery` `8d8ac622` → `068d02a0` first (work-above-bookmark rule).
Duplicated `43d09b9d75ad.."subagent-recovery"` (12 commits, originals
untouched), rebased the duplicates onto `7ba5f3e5b220`: 8 commits conflicted.

### Divergence incident (shared-repo op-log hazard)

Between the rebase and the first rebuild command, an external op-log merge
(the documented sibling-agent hazard) resurrected the **pre-rebase duplicate
versions of the four bottom docs commits** as divergent siblings on the old
`43d09b9d` lineage. The first rebuild commit accidentally parented onto the
old-lineage sibling. Recovery: abandoned the scratch commit and the four stale
siblings; divergence cleared; the rebased versions
(`3bfade9f`/`666d415e`/`3e09cd1c`/`4cd5990f`) remained sole and correct. All
later steps re-verified ids at use time.

### Rebuild instead of in-place resolution

The canonical jj conflict flow (`jj new` + `jj squash`/`jj edit`) is forbidden
by the freshen discipline, so per the recorded lesson ("build replacements
directly on the destination base") the 8 conflicted duplicates were abandoned
and their commits **rebuilt** on the rebased docs tail, hand-applying each
original commit's delta:

- **Auto-merged content pulled verbatim** from the conflicted duplicates
  (jj had already merged these cleanly): `promise/adapter.ts`,
  `test/plugin/host.ts`, docs `index.mdx`, `effect/session.ts`,
  `promise/session.ts`, the test file, `client/src/promise/api.ts`.
- **Modify/delete conflicts resolved per the playbook**: `runtime.ts` and
  `plugin-session.types.ts` restored byte-for-byte from the original feature
  commits (upstream's deletion is exactly the e76e90b7 move the compose
  overrode; the restored files are the feature-tip content, 181 and 54 lines).

### Conflicts: 3 files, all resolved mechanically

1. **`packages/core/src/plugin/host.ts`** (3 conflict regions, identical
   geometry through the stack). Upstream's intent: drop the runtime
   indirection, yield services directly, add a `requirements` LayerNode group
   and the `Pick<Interface, "list">` make signature, plus an editor-rename
   import. Feature's intent: cursor codecs, `sessionList`/`sessionMessages`
   helpers, and `list`/`children`/`messages`/`active`/`inbox.list` context
   members. Resolution: **union everywhere** — upstream's LayerNode import,
   Pick signature, and requirements group adopted; feature's codecs/helpers/
   members re-homed inside them; feature helpers placed after the requirements
   group (the compose's layout). Rationale: preserves both sides — the host is
   upstream's new direct-service shape; the reads ride the restored runtime.
2. **`packages/core/src/plugin/runtime.ts`** (modify/delete): restored
   byte-for-byte from the feature tip per the compose playbook. Upstream's
   deletion removed the indirection *architecture*; the compose decided the
   feature keeps its runtime-backed contract, so the file returns whole.
3. **`packages/core/test/plugin-session.types.ts`** (modify/delete): same
   playbook restore (type-test file, no importer; typecheck-only).

**Compose-playbook wiring** (the compose's recorded adaptation, transcribed
onto the new base): `host.ts` gains `import { PluginRuntime } from
"./runtime.js"`, `const runtime = yield* PluginRuntime.Service` after the
`locations` yield, and `PluginRuntime.node` in the requirements group;
`test/plugin/fixture.ts` (a file the old line never touched — see diffstat

rebased feature commits (host wiring in the paginated-reads commit, fixture

the sequencing; the line tip is green.
