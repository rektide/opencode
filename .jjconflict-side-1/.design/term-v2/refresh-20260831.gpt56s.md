## Implemented capability

- Session epilogues retain only hydrated primitive Session facts.
- The first renderer destroy edge freezes one immutable presentation using an
  explicit clock before Solid and plugin disposal.
- An outer interruption-safe Effect finalizer writes after inner cleanup and
  awaits the Node stdout callback.
- Output failures cannot replace the original success, failure, or
  interruption outcome.
- `SIGHUP`, `SIGINT`, and `SIGTERM` preserve the provisional `0`, `130`, `130`
  exit policy while writing exactly one complete epilogue.
- `Active` renders `running` for cached running state; idle state uses
  `max(updated, idle ?? updated)`.
- Session route exit, deletion, switching, stale old-Session updates, and late
  hydration cannot leak an invalid or previous Continue command.
